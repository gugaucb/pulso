# 房主快速入门指南 — PULSO Tor 与 PULSO 本地 / 隧道

[Português (BR)](../pt-br/host-quickstart.md) · [English](../en/host-quickstart.md) · [Español](../es/host-quickstart.md) · [简体中文](./host-quickstart.md)

本指南用通俗语言说明（全程无需打开命令行终端）**房主**如何下载、启动并安全关闭 **PULSO Tor**（**Tor 模式**）或 **PULSO 本地 / 隧道**（**标准模式**）。

> [!TIP]
> 在运行任何下载的安装包之前，建议先按照[密码学校验、离线使用与网桥指南](./verification-offline-bridges.md)验证签名和哈希。

---

## 1. 应下载哪一个桌面版本？

官方发布页面提供标准命名文件 `pulso-tor-vX.Y.Z-<系统>-<架构>.<扩展名>` 与 `pulso-local-vX.Y.Z-<系统>-<架构>.<扩展名>`（**PULSO Tor** 同时提供备用镜像）：

- **PULSO Tor**（**Tor 模式**）：适合需要将**房间**发布到 `.onion` 地址、隐藏自身 IP 且不在磁盘残留痕迹的**房主**。仅支持纯文本**阅后即焚消息**（禁用**视频通话**），**访客**需通过 **Tor Browser** 访问。
- **PULSO 本地 / 隧道**（**标准模式**）：适合位于家用路由器或 CGNAT 之后、希望用普通浏览器开启**房间**的**房主**，支持**阅后即焚消息**与可选**视频通话**。

| 操作系统 | 下载文件格式 |
| :--- | :--- |
| **macOS**（Apple Silicon `arm64` 或 Intel `x64`） | `.dmg` |
| **Windows**（`x64`） | `.exe` 安装包或免安装便携版 `.zip` |
| **Linux**（`x64` 或 `arm64`） | `.AppImage`（便携单文件）或 `.deb`（Ubuntu/Debian） |

## 2. v1 无付费证书时如何 3 步打开（免终端）

在 v1 版本中，桌面端尚未购买商业 Apple Developer 或 Microsoft Authenticode 代码签名证书。因此**首次打开**时，系统会弹出常规安全提示。按以下 3 步即可放行，无需使用终端：

### macOS Sequoia（Gatekeeper 门禁）

PULSO 的 `.dmg` 在构建时已完成本地 `ad-hoc` 预签名，可在 Apple Silicon 和 Intel Mac 上正常运行。首次打开时：

1. 打开 `.dmg`，将 PULSO 拖入 **应用程序（Applications）**（或直接从 U 盘运行）并双击。弹出未识别开发者提示时，点击 **好（OK）** 或 **完成**。
2. 打开左上角苹果菜单中的 **系统设置**，进入 **隐私与安全性**。
3. 向下滚动到 **安全性** 区域，在 PULSO 的提示旁点击 **仍要打开**，并使用指纹或密码确认。自第二次起即可直接打开。

### Windows（SmartScreen 筛选器）

可直接运行 `.exe` 安装程序，或将便携版 `.zip` 解压到任意文件夹或 U 盘后双击 `pulso-desktop.exe`：

1. 双击下载的文件。如果出现蓝色的 **Microsoft Defender SmartScreen** 提示（*“Windows 已保护你的电脑”*），请不要关闭窗口。
2. 点击提示文字下方的 **更多信息** 链接。
3. 点击底部出现的 **仍要运行** 按钮。

### Linux（`.AppImage` 或 `.deb`）

- **使用 `.AppImage`（免安装）：** 在文件管理器中右键点击 `.AppImage` 文件 > **属性** > **权限** > 勾选 **允许作为程序执行文件**（或同类开关），关闭属性窗口后双击即可启动。
- **使用 `.deb`（Ubuntu / Debian / Mint）：** 双击 `.deb` 文件打开系统图形化软件安装器，点击 **安装** 即可。

## 3. 使用 PULSO Tor（Tor 模式）

1. 打开 **PULSO Tor**。在启动**实例**前选择连接模式：
   - **直连模式：** 适用于无封锁网络的快速默认连接。
   - **内置 Snowflake：** 通过 `lyrebird` 一键自动突破审查。
   - **自定义网桥：** 粘贴从[密码学校验与网桥指南](./verification-offline-bridges.md)官方渠道获取的网桥行。网桥仅保存在内存及退出时清除的临时目录中。
2. 点击 **启动 Tor 实例**，在面板查看可读进度（绝不暴露网桥 IP）。
   - 若网络封锁直连导致引导停滞，面板会弹出明显提示并提供一键按钮 **使用 Snowflake 重启（抗审查）** 或 **粘贴自定义网桥**。
3. `.onion` 地址就绪后，默认浏览器会自动打开 `127.0.0.1` 的**房间**页面（也可点击 **在浏览器中打开房间**）。
4. 创建**房间**后，将**房间代码**和 `.onion` 地址发给**访客**，请对方使用 **Tor Browser** 打开。关闭**房间**或**静默倒计时**归零后，所有**阅后即焚消息**立即销毁。

---

## 4. 使用 PULSO 本地 / 隧道（标准模式）

1. 打开 **PULSO 本地 / 隧道**。在建立任何外部连接前，面板会说明隧道信任模型：
   - 反向隧道为**可选开启（opt-in）**：在您点击 **启动实例并开启隧道** 之前，不会向公网暴露任何端口。
   - 如果只在本地 Wi-Fi/局域网内使用，请点击 **仅本地启动**。
2. 开启 Cloudflare 隧道后，**实例**无需注册或配置路由器端口转发即可生成 `https://...trycloudflare.com` 访问地址，并在默认浏览器中打开**房间**。
3. **参与者透明提示：** **房主**和**访客**都会在**房间**内看到清晰标识，说明 Cloudflare 中继可看到网络元数据和 IP 地址，而**阅后即焚消息**仍在浏览器内保持端到端加密（密钥保存在链接 `#` 片段中，绝不会发送给服务器）。
4. **尽力而为（best-effort）视频通话：** 网络允许直连时自动通过 STUN 建立 P2P 通话。若对称 NAT 或企业防火墙阻止媒体直连，纯文本**阅后即焚消息**仍可正常收发；如有需要，可在启动前展开面板中的 **高级选项（仅内存中的外部 TURN）** 填入外部 TURN 凭据（仅驻留内存）。

## 5. 系统托盘生命周期与“关闭并清除痕迹”

- **关闭窗口不会中断房间：** 当**实例**处于运行状态时，关闭面板窗口只会将其最小化到**系统托盘**（macOS 顶部菜单栏 / Windows 与 Linux 通知区域），避免误操作导致**房间**掉线。
- **彻底退出并清理：** 打开托盘菜单（v1 原生托盘菜单项名称为 **Encerrar e purgar rastro**）或点击面板中的 **关闭并清除痕迹** 按钮，即可关闭所有活跃**房间**、终止 Tor 或隧道进程树，并立即删除在 `os.tmpdir()` 下创建的临时目录。

---

## 6. 零后台回连策略（zero phone-home）

PULSO 的所有桌面发行版均绝不在后台自动检查更新：

- **PULSO 本地 / 隧道：** 面板提供可选的手动 **检查更新** 按钮，仅在点击时发起一次按需查询并在浏览器中打开发布页面（不会自动下载或安装）。
- **PULSO Tor：** 发起**零明网请求**。面板仅显示当前应用及内置 Tor 版本，并提供官方发布页面链接供您通过 **Tor Browser** 手动核对（或使用[校验与镜像指南](./verification-offline-bridges.md)中的备用镜像）。
